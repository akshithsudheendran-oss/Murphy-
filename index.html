Murphy

An automated, lightweight Dynamic Application Security Testing (DAST) scanner that evaluates the attack surface of web applications from an external perspective.

Start Scanning Create Account

What Murphy Does

Murphy runs five independent security modules against a target URL and reports findings with severity levels.

SQLi

SQL Injection

Tests URL parameters with common payloads and detects database error signatures.

XSS

Cross-Site Scripting

Injects script payloads into inputs and checks if they reflect unescaped in the response.

HTTP

Security Headers

Verifies presence of HSTS, CSP, X-Frame-Options, and X-Content-Type-Options.

PORT

Port Scanner

Checks common ports (21, 22, 80, 443, 3306, 8080) for unexpected exposure.

PATH

Admin Panel Finder

Probes common admin paths (/admin, /wp-admin, /phpmyadmin).

How It Works

1

Enter URL

Paste the target website URL you own or have permission to test.

2

Automated Scan

Five modules run in sequence — SQLi, XSS, Headers, Ports, Admin Finder.

3

Get Report

View findings with severity and download a PDF report for your records.

Ethical Disclaimer

Murphy is for educational and authorized testing only. Scanning websites without explicit permission is illegal under the IT Act, 2000 and similar laws worldwide. Only test sites you own or have written consent to test.
